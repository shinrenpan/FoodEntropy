# App Store Badge

`download-on-the-app-store.svg` 是 Apple 官方的「Download on the App Store」徽章
（黑底 en-us 版），下載自 Apple Marketing Tools：

```sh
curl -sL -o download-on-the-app-store.svg \
  "https://toolbox.marketingtools.apple.com/api/v2/badges/download-on-the-app-store/black/en-us"
```

使用時須遵守 Apple 的
[Marketing Resources and Identity Guidelines](https://developer.apple.com/app-store/marketing/guidelines/)：
不得改變顏色、比例或加上效果，且必須連往本 App 的 App Store 頁面
（`https://apps.apple.com/app/id6793926521`）。
